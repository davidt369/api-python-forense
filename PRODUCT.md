# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Next.js 14, React 18, Tailwind CSS, Lucide Icons, shadcn/ui in `frontend/` directory.

## Users

General Public, Corporate/Legal Clients, and External Verification Parties requiring digital forensic image analysis and certified verification reports.

## Product Purpose

A digital forensic certification platform ("API Forense – Plataforma de Certificación Digital") that allows users to analyze images for tampering (ELA, EXIF, histogram analysis), generate tamper-evident PDF certificates with cryptographic QR hashes, and verify forensic reports publicly.

## Positioning

High-trust, professional digital forensic analysis service offering verifiable cryptographic proof of media integrity and automated reporting.

## Operating Context

Web browser application (responsive across desktop and mobile) used for marketing forensic services, showcasing analysis methodologies, providing immediate certificate verification lookup, and driving client onboarding.

## Capabilities and Constraints

- Primary landing page located in `frontend/app/page.tsx`.
- Dark mode supported via `next-themes`.
- Lucide React icon suite available.
- Visual aesthetic must feel extraordinary, high-precision, and modern (glassmorphism, subtle glowing grid accents, smooth dynamic micro-animations).

## Brand Commitments

- High-tech, forensic, trustworthy identity.
- Palette featuring deep slate/navy midnight tones, vivid cyan/emerald accents, crisp typography, and sleek glass paneling.

## Evidence on Hand

- Existing Next.js codebase in `frontend/` with Tailwind CSS, `lucide-react`, and `framer-motion` / CSS keyframe setup.
- Existing landing page component at `frontend/app/page.tsx`.

## Product Principles

1. Forensic Precision & Visual Trust: Design must communicate rigorous analytical accuracy, cryptographic security, and professionalism.
2. Out-of-Distribution Craft: Engaging interactive visual elements, micro-animations, dynamic hover cards, glowing badges, and live demo widgets.
3. Seamless User Journey: Intuitive hierarchy guiding visitors from hero value proposition through methodology breakdown, live hash verification preview, service tiers, and explicit action pathways.

## Accessibility & Inclusion

WCAG AA compliance for color contrast, readable text hierarchy, interactive state feedback, and responsive layout scaling.
